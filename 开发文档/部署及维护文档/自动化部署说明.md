# 宇小兔读书 · 服务器自动化部署说明

> 适用：**Ubuntu 24.04 LTS**（已验证 noble）  
> 场景：腾讯云全新/重置服务器，一键部署生产环境

---

## 一、部署架构

```
浏览器 → Docker Nginx (:80)
           ├─ /              → frontend/dist
           ├─ /api/v1/orders|member → Java trade (:8081)
           └─ /api、/uploads → Python API (:8000)
宿主机 MySQL (127.0.0.1:3306) ← Docker 经 host.docker.internal 连接
```

---

## 二、本目录文件

| 文件 | 说明 |
|------|------|

| `upload-and-deploy.ps1` | Windows 本机：打包 + 上传 + 远程部署 |

## 三、最快部署（推荐）

### 步骤 1：本机准备配置

```powershell
cd E:\AI项目\YuXiaoTuAIGC\YuXiaoTuBook\开发文档\部署及维护文档
copy server-deploy.env.example server-deploy.env
notepad server-deploy.env
```

编辑 `server-deploy.env`，至少修改：

```ini
SERVER_IP=175.178.119.166
DOMAIN=www.yuxiaotubook.com
MYSQL_PASSWORD=你的强密码
RUN_SEED=true
INSTALL_ENV=true
```

可选上传介绍视频：

```ini
INTRO_VIDEO_PATH=E:\AI项目\YuXiaoTuAIGC\YuXiaoTuBook\YuXiaotuBook\backend\uploads\yuxiaotu-intro.mp4
```

### 步骤 2：一键打包上传并部署

```powershell
.\upload-and-deploy.ps1 -RebuildFrontend
```

脚本会自动：
1. 调用 `pack-release.ps1` 打 tar 包（含最新前端 dist）
2. `scp` 上传 tar、`server-deploy.sh`、`server-deploy.env` 到服务器 `/root/`
3. SSH 远程执行 `server-deploy.sh`

### 步骤 3：验证

- 前台：`http://你的域名/`
- 后台：`http://你的域名/admin/login`
- 默认账号：`admin` / `admin123456`（**请立即修改**）

## 四、手动分步部署

若不想用 `upload-and-deploy.ps1`：

### 1. 本机打包

```powershell
cd E:\AI项目\YuXiaoTuAIGC\YuXiaoTuBook\YuXiaotuBook\deploy
.\pack-release.ps1 -RebuildFrontend
```

### 2. 上传到服务器

```powershell
$IP = "175.178.119.166"
scp ".\release\yuxiaotu-book-ubuntu2404-*.tar.gz" root@${IP}:/root/
scp "E:\AI项目\YuXiaoTuAIGC\YuXiaoTuBook\开发文档\部署及维护文档\server-deploy.sh" root@${IP}:/root/
scp "E:\AI项目\YuXiaoTuAIGC\YuXiaoTuBook\开发文档\部署及维护文档\server-deploy.env" root@${IP}:/root/
```

### 3. 服务器执行

```bash
sudo -i
sed -i 's/\r$//' /root/server-deploy.sh /root/server-deploy.env
chmod +x /root/server-deploy.sh
bash /root/server-deploy.sh
```

## 五、脚本执行流程（server-deploy.sh）

1. 读取 `/root/server-deploy.env`
2. 解压 `/root/yuxiaotu-book-ubuntu2404-*.tar.gz` → `/usr/local/projects/yuxiaotu/app`
3. 安装 Docker / Node.js / MySQL（`INSTALL_ENV=true`）
4. 自动生成 `/usr/local/projects/yuxiaotu/env/prod.env`
5. 执行 `deploy.sh`（构建前端 + 启动 Docker）
6. 重建 Nginx（避免 502）
7. 执行 `seed` 初始化数据（`RUN_SEED=true`）
8. 可选：更新图书视频 / 电子书脚本
9. 健康检查 `curl http://127.0.0.1/api/health`

## 六、后续更新代码（不清库）

上传新 tar 包后，在 `server-deploy.env` 中设置：

```ini
RUN_SEED=false
INSTALL_ENV=false
```

再执行：

```bash
sudo bash /root/server-deploy.sh
```

或本机：

```powershell
.\upload-and-deploy.ps1 -RebuildFrontend
```

（需在 `server-deploy.env` 中设 `RUN_SEED=false` `INSTALL_ENV=false`）

## 七、腾讯云安全组

入站仅开放：

| 端口 | 用途 |
|------|------|
| 22 | SSH |
| 80 | HTTP |
| 443 | HTTPS（可选） |

**不要**对公网开放 3306、8000、8081。

## 八、常见问题

| 问题 | 处理 |
|------|------|
| 502 Bad Gateway | `docker compose ... up -d --force-recreate nginx` |
| backup-mysql 1698 | 脚本已含 `fix_mysql_root_auth`；手动：`sudo mysql` 改 root 密码 |
| git clone 失败 | 服务器连不上 GitHub，用 tar 包部署 |
| 后台仍是旧界面 | 确认 tar 包用 `-RebuildFrontend` 打包 |
| 密码含 `@` | 脚本自动 URL 编码写入 DATABASE_URL |

## 十、维护命令

```bash
ENV=/usr/local/projects/yuxiaotu/env/prod.env
DEPLOY=/usr/local/projects/yuxiaotu/app/YuXiaotuBook/deploy

# 查看容器
docker compose -f $DEPLOY/docker-compose.prod.yml --env-file $ENV ps

# 查看 API 日志
docker logs yuxiaotu-api-prod --tail 100

# 备份数据库
cd $DEPLOY && ./scripts/backup-mysql.sh

# 重启全部
docker compose -f $DEPLOY/docker-compose.prod.yml --env-file $ENV up -d --force-recreate
```
