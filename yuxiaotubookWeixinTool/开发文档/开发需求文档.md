## 一、项目背景与目标

### 1.1 背景

宇小兔读书 Web 用户端已具备完整 C 端能力：首页氛围、书单搜索、书籍详情（视频解读 + 电子书）、每日读书、会员、收藏/历史、购书订单等。运营内容均通过 **Admin 后台** 配置，数据存储在 **同一 MySQL**。

微信小程序作为 Web 的 **平行用户入口**，不单独维护内容，不重复建设后台。

### 1.2 核心目标

| 目标 | 说明 |
|------|------|
| **功能对齐** | 小程序覆盖 Web 用户端全部重要功能（见 §三） |
| **数据同源** | 与 Web 共用 API、JWT、MySQL；Admin 改内容，小程序即时生效 |
| **体验一致** | 页面信息架构、文案、视觉气质与 Web 用户端保持一致 |
| **可演进** | 一期账号密码登录 + 模拟支付；二期微信登录 + 微信支付 |

### 1.3 非目标（本期不做）

- 不新建小程序专用 Admin 或 CMS
- 不在小程序仓库内维护书籍/视频/每日内容数据
- 不实现 Admin 管理功能
- 不替换现有 Web 用户端

## 二、数据联动原则（与 Web / Admin 的关系）

```text
                    ┌─────────────────────────┐
                    │  Admin 后台（Vue3）      │
                    │  SiteConfig / 书籍 / 视频 │
                    │  每日读书 / 会员套餐 / 订单 │
                    └───────────┬─────────────┘
                                │ 读写
                                ▼
                    ┌─────────────────────────┐
                    │  MySQL（yuxiaotu_book）   │
                    │  uploads / site_config   │
                    └───────────┬─────────────┘
                                │ REST API
              ┌─────────────────┼─────────────────┐
              ▼                 ▼                 ▼
        Web 用户端          微信小程序          （未来 App）
        Vue3 :5188         uni-app 编译
```

### 2.1 联动规则

| 规则 | 说明 |
|------|------|
| **单一数据源** | 书籍、分类、视频 URL、站点氛围、每日读书、会员套餐均来自现有表与 API |
| **配置即时生效** | Admin 保存 `site-config`、上传 homePage 视频、修改书籍后，小程序下次请求即获得新数据（无小程序发版依赖） |
| **用户账号互通** | 同一 `users` 表；Web 注册的账号可在小程序登录；收藏/历史/订单/VIP 状态共享 |
| **媒体 URL 一致** | 封面 `/uploads/`、占位 `/placeholders/`、视频 `/media/v/homePage|bookReview/` 与 Web 相同规则 |
| **交易走 Java** | 订单、会员订阅与 Web 相同，走 `yuxiaotu-trade-service`（8081） |

### 2.2 Admin 操作 → 小程序表现对照

| Admin 操作 | 影响的小程序页面 |
|------------|------------------|
| 氛围配置：宣传标题、每日一句、背景视频 | 首页 Hero |
| 氛围配置：主推书 `featured_book_id` | 首页「今日主推」 |
| 书籍管理：上下架、价格、库存 | 书单、详情、下单 |
| 解读视频管理 | 详情页视频播放 |
| 每日读书发布 | 每日读书 Tab |
| 会员套餐管理 | 会员中心 |
| 订单发货（物流单号） | 个人中心 · 收发货 |

## 三、功能范围（与 Web 用户端 1:1 映射）

### 3.1 页面清单

| 序号 | 小程序页面 | 对应 Web 路由 | 需登录 | 优先级 |
|------|------------|---------------|--------|--------|
| P01 | 首页 | `/` | 否 | P0 |
| P02 | 书单 | `/books` | 否 | P0 |
| P03 | 书籍详情 | `/books/:id` | 否* | P0 |
| P04 | 每日读书 | `/daily` | 否 | P0 |
| P05 | 会员中心 | `/member` | 否* | P0 |
| P06 | 登录 | `/login` | 否 | P0 |
| P07 | 注册 | `/register` | 否 | P0 |
| P08 | 我的订单 | `/user/orders` | 是 | P0 |
| P09 | 我的收藏 | `/user/favorites` | 是 | P1 |
| P10 | 浏览记录 | `/user/history` | 是 | P1 |
| P11 | 个人中心 | `/user/center` | 是 | P0 |

\* 未登录可浏览；收藏、下单、开通会员需登录。

### 3.2 TabBar 结构（建议）

| Tab | 页面 | 图标语义 |
|-----|------|----------|
| 首页 | P01 | 首页 |
| 书单 | P02 | 书籍 |
| 每日 | P04 | 日历/读书 |
| 我的 | P11 | 用户 |

会员中心（P05）、登录/注册从「我的」或详情页跳转，不占 Tab。

### 3.3 功能明细

#### P01 首页

- 拉取 `GET /site/config`：背景视频轮播（`bg_videos`）或静态图（`bg_url`）
- 展示 `promo_title`、`daily_sentence`
- 搜索框：跳转书单并带 `keyword`（或首页内嵌搜索）
- 分类快捷标签 → 书单筛选
- `GET /home/featured` 今日主推
- `GET /home/hot-books` 热门书籍网格
- 底部信任条（与 Web 四项文案一致）

**小程序适配：**

- 背景视频使用 `<video>` 组件，注意流量与性能（见技术选型文档）
- 视频 URL 使用 `/media/v/homePage/{name}` 形式

#### P02 书单

- `GET /categories` 分类 Chip
- `GET /books`：分页、`sort=hot|new`、`category_id`、`keyword`
- 搜索联想（可选 P1）：本地 debounce 调 `/books?keyword=&page_size=8`

#### P03 书籍详情

- `GET /books/{id}`：封面、作者、分类、摘要、亮点、价格、库存、`has_video`、`ebook_content`
- **视频解读**（有 `has_video`）：
  - `GET /books/{id}/play-auth`
  - 游客试看 `max_duration`（默认 180s），试看结束引导登录
  - 登录用户 `full_access=true` 看全片
- **电子书解读**（有 `ebook_content`）：可折叠阅读区，字号/主题切换（简化版 EbookReader）
- 收藏：`POST /favorites`（需登录）
- 购买纸质书：填写收货信息 → Java 下单流程
- `GET /books/{id}/similar` 相似推荐

#### P04 每日读书

- `GET /daily/today` 今日内容
- `GET /daily/list` 历史列表分页
- `POST /daily/{id}/like` 点赞
- 关联书籍跳转详情

#### P05 会员中心

- `GET /member/packages` 套餐列表
- 登录用户：`POST /member/subscribe` → `POST /member/orders/{id}/mock-pay`（一期）
- 展示权益说明（`rights` JSON）

#### P06/P07 登录与注册

- **一期**：与 Web 相同，用户名 + 密码
  - `POST /auth/login`、`POST /auth/register`
  - Token 存 `wx.setStorageSync('token')`
- **二期（规划）**：微信 `wx.login` + 后端 code2session 绑定/自动注册

#### P08 我的订单

- `GET /orders`（Java）订单列表与状态

#### P09/P10 收藏与浏览记录

- `GET /favorites`、`GET /history`
- P1：支持 `DELETE /favorites/{book_id}` 取消收藏

#### P11 个人中心

- `GET /auth/me` 用户信息 + VIP
- `GET /member/status` 会员有效期
- `GET/PUT /user/preferences` 读书喜好
- `GET /user/orders/shipping` 收发货追踪
- 入口：订单、收藏、历史、会员

### 3.4 全局能力

| 能力 | 说明 |
|------|------|
| 登录态 | 启动时读 token，调 `/auth/me` 刷新用户与 VIP |
| 401 处理 | 清 token，跳转登录页并带 `redirect` |
| 客服 | `button open-type="contact"` 或复制客服邮箱（与 Web 浮窗一致） |
| 分享 | 书籍详情、每日读书支持 `onShareAppMessage` |
| 下拉刷新 | 首页、书单、每日、订单列表 |

## 四、API 依赖清单

### 4.1 Python API（`/api/v1`，端口 8000）

| 模块 | 端点 | 小程序用途 |
|------|------|------------|
| auth | POST register/login, GET me | 登录注册 |
| site | GET site/config | 首页氛围 |
| home | GET featured, hot-books | 首页 |
| categories | GET categories | 分类 |
| books | GET list/detail/play-auth/similar, POST play-report | 书单/详情 |
| daily | GET today/list, POST like | 每日读书 |
| favorites | POST/GET/DELETE favorites | 收藏 |
| history | GET history | 浏览记录 |
| user | GET/PUT preferences, GET orders/shipping | 个人中心 |
| media | GET /media/v/{category}/{name} | 视频流 |

### 4.2 Java 交易 API（`/api/v1`，端口 8081）

| 端点 | 用途 |
|------|------|
| POST/GET /orders | 购书下单与列表 |
| POST /orders/{id}/mock-pay | 一期模拟支付 |
| GET /member/packages | 套餐 |
| GET /member/status | VIP 状态 |
| POST /member/subscribe | 订阅 |
| POST /member/orders/{id}/mock-pay | 会员开通 |

### 4.3 请求规范（与 Web 一致）

```http
GET https://www.yuxiaotubook.com/api/v1/books?page=1
Authorization: Bearer {jwt_token}
Content-Type: application/json
```

响应信封：`{ "code": 200, "msg": "操作成功", "data": ... }`

## 五、非功能需求

### 5.1 性能

| 指标 | 目标 |
|------|------|
| 首屏可交互 | ≤ 2.5s（4G） |
| 列表分页 | 每页 12 条，与 Web 一致 |
| 图片 | 封面使用 CDN/HTTPS，lazy-load |
| 视频 | 首页背景仅 1 路播放；详情页点击后加载 |

### 5.2 安全

- 全站 HTTPS
- Token 仅存本地 Storage，不写日志
- 视频 URL 使用 `/media/v/` 无扩展名路径
- 小程序后台配置 request 合法域名

### 5.3 兼容性

- 微信基础库 ≥ 2.25.0
- iOS / Android 微信客户端主流版本

### 5.4 微信审核

- 图书解读视频需有完整资质说明（出版物相关类目）
- 一期 mock-pay 仅用于内测；正式上线需接微信支付
- 用户协议、隐私政策页面（可 WebView 或原生页）

## 八、风险与对策

| 风险 | 对策 |
|------|------|
| 首页多视频流量大 | 转码 720p + faststart；小程序限制同时解码路数 |
| 微信审核支付 | 一期内测 mock；上线前接微信支付 |
| 域名未备案/未配置 | 提前在微信公众平台配置 request 合法域名 |
| JWT 7 天过期 | 401 引导重新登录；二期可做 refresh |
| 小程序包体限制 | 静态资源走 CDN，不打包大视频 |
